CONFIGURATION

链接配置只影响当前设备。

同一份静态站点，在电脑和手机上可以各自指向不同的受控地址。

01 / OPEN

打开配置入口

点击页头或页脚的“配置链接”，输入完整的 http 或 https 地址。

02 / VALIDATE

安全校验

本机路径、file 协议、账号密码和危险协议会被直接拒绝。

03 / STORE

保存到浏览器

设置存储在当前浏览器，不写入仓库，也不会同步到其他设备。

!
ComfyUI 默认不应对公网开放。

如果手机需要访问，应使用可信局域网、VPN 或带身份验证的反向代理。 AI 生图专项使用 Worker 密码门与应用口令，不直接暴露 8787 或 ComfyUI 管理端口。
